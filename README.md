# TikTok Style References

레퍼런스 이미지 저장소 (썸네일 스타일 생성용)

## 폴더 구조

```
├── COMIC_STARBURST/   # 집중선 스타일
├── HEART_PINK/        # 핑크 하트 스타일
├── NEON_POP/          # 네온 팝 스타일
├── MINT_ROCKET/       # 민트 로켓 스타일
└── SEASONAL_CHRISTMAS/ # 크리스마스 스타일
```

## 사용법

각 폴더에 해당 스타일의 레퍼런스 이미지를 넣으면 됨.

Raw URL 형식:
```
https://raw.githubusercontent.com/simpsonpd/tiktok-style-references/main/{스타일}/{파일명}
```
